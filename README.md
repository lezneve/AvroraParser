# AvroraParser

## що це

термінальний скрипт для пошуку товарів і знижок у магазинах «аврора». окремі скрипти синхронізують каталоги «аврори» та «копійочки» з postgresql.

скрипт ходить у мережу: до api цінників і сайту «аврори».

## запуск

потрібні python 3.12 або новіший і [uv](https://docs.astral.sh/uv/). запускати з кореня репозиторію.

```sh
uv sync
uv run avrora_parser.py
```

у меню: пошук товару за штрихкодом, сканування знижок, зміна магазину, зміна kt-фільтра. магазин і фільтр зберігаються в `config.json`. kt вводяться через кому, `all` означає всі категорії.

сканування перебирає штрихкоди від 1 до 150000 і показує один рядок прогресу. наприкінці — таблиця з найбільшими знижками. запити, на які після трьох спроб немає відповіді, перелічуються в підсумку. колір вимикається змінною `NO_COLOR`.

### синхронізація каталогів

| команда | що робить |
| --- | --- |
| `uv run dumper_avrora.py` | товари й ціни «аврори» в таблицю `products` |
| `uv run dumper_kopiyochka_v3.py` | каталог «копійочки» в таблицю `kopiyochka_products` |

обом потрібен локальний файл `.env`:

| змінна | значення |
| --- | --- |
| `DATABASE_URL` | рядок підключення до postgresql |
| `R2_ACCESS_KEY`, `R2_SECRET_KEY` | ключі доступу до cloudflare r2 |
| `R2_ENDPOINT`, `R2_BUCKET` | s3-сумісна адреса r2 і назва бакета |
| `CDN_URL` | публічна базова адреса зображень |

для «копійочки» ще потрібен виконуваний файл `obscura` у `PATH` або в каталозі `obscura/` поруч зі скриптом.

## структура

| файл | що в ньому |
| --- | --- |
| `avrora_parser.py` | меню, пошук, вивід |
| `avrora_api.py` | запити до api, моделі магазину й товару, сканування |
| `common.py` | конфіг, запити з повтором, рядок прогресу, таблиця |
| `dumper_avrora.py`, `dumper_kopiyochka_v3.py` | синхронізація з postgresql |
